# V1-H.37C — Bilingual example quality review

Scope: read-only review of **60 published examples** (12 German noun cards × 5). The production database is unchanged. All examples contain both German and English text. This editorial review assesses grammar, translation fidelity, naturalness, and sense coverage; it is not a guarantee of exhaustive linguistic correctness.

## Proposed editorial improvements (not applied)

1. **Beschwerde:** replace one redundant medical example with “Ich möchte eine Beschwerde über den Service einreichen.” → “I would like to file a complaint about the service.” This teaches the distinct non-medical sense.
2. **Gewohnheit:** translate “Sie hat die Gewohnheit, früh aufzustehen.” as “She is in the habit of getting up early.” to improve idiomatic English.
3. **Miete:** consider a brief usage note explaining “Warmmiete” (including certain additional costs) versus “Kaltmiete” (base rent). Do not imply that warm rent necessarily includes *all* utilities.
4. **Bewerbung:** consider changing the accepted-application example to an unambiguous application-status context.

## Publication safeguards

- These are proposed improvements, not automatic corrections.
- Preserve five examples per word card.
- Recheck published search and card rendering after any approved content edit.
- Keep grammar and translation review separate from structural validation.
